# Английский путь

Проект с 2026-11-09. Сайт для изучения английского по школьной программе 5–11 класса, уровень до B2. Пользователь — репетитор, сайт для небольшой группы учеников. Главное — содержание, а не оболочка. Ориентиры по темам: Spotlight и Oxford (Elementary → Upper-Intermediate). **Тексты учебников не копируем**: берём порядок тем и грамматику, всё пишем сами.

**Статус (2026-11-09, версия 2):** готовы классы 5–11 (199 уроков), справочник грамматики (48 тем A1–B2) со схемами. Дизайн — монохром в академическом стиле по референсу пользователя. Ждём отзыв.

## Как запустить

- Открыть `site/index.html` двойным щелчком (интернет нужен только для шрифтов).
- Или сервер: конфиг `english-path` в `.claude/launch.json` → http://localhost:5175.
- Отладка: `?debug` в адресе → `window.__ep`.

## Устройство

- `site/data/grammar.js` — справочник: 48 тем. Каждая тема — наглядные блоки (формула из плашек, линия времени, стрелка «слово переезжает», превращения a → b, таблица, сравнение, примеры с озвучкой, слова-подсказки) + база упражнений. Формат описан в начале файла.
- `site/data/grade5.js … grade11.js` — программы классов. 5 класс: 11 модулей × 5 уроков. 6–11: 8 модулей × 3 урока (уроки длиннее). Урок = тема грамматики (`gr`) + 8 слов + 5 предложений + «раскрой скобки» (`f`).
- `site/app.js` — профили, генерация заданий, плеер, карта, справочник, повторение, достижения.
- `site/style.css` — монохром: белый, серый, чёрный. Заголовки — Cormorant Garamond, текст — Onest. Фишка — большие контурные цифры класса и модуля.

## Как работает

- Урок 6–11 класса: схема правила → слова → ~20 заданий (выбор, пары, пропуски, раскрой скобки, собрать фразу, на слух, ввод). 5 класс — ~17 заданий.
- Тест модуля: 20 заданий, половина — ввод. 80% = модуль закрыт (можно экстерном).
- Итоговая класса: 40 заданий, 80% = класс сдан, открывается следующий. Так же «перепрыгивают» классы, которые знают.
- «Раскрой скобки» проверяется строго (без «почти»): ошибка в окончании — ошибка.
- Повторение: слова через 1, 2, 4, 7, 15, 30 дней; правила с ошибкой — завтра и через 3 дня.
- План: цель (свой класс / A2 / B1 / B2), минуты в день, срок. До B2 по программе сайта ≈ 70 часов; честно пишем, что для настоящего B2 нужны чтение и разговор.
- Видео: кнопка «Видеоуроки на YouTube» в каждой теме открывает поиск по готовому запросу (ссылки на конкретные ролики не вставляли — не проверены).

## Идеи на потом

- Сервер с аккаунтами и кабинет репетитора.
- Проверенные ссылки на конкретные видео вместо поиска.
- Тексты для чтения и аудирования на каждый модуль; задания в формате ОГЭ/ЕГЭ.
- Озвучка через ElevenLabs.

## Факты

- Spotlight 5–9: Ваулина, Дули, Подоляко, Эванс. 10–11: Афанасьева, Дули, Михеева.
- По Oxford English Corpus 100 самых частых слов = ~50% слов в текстах, но это служебные слова.
